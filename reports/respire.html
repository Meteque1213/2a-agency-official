Findings critiques

Une certification inventée. Deux drifts commerciaux.

Drift primaire · Certification B Corp · Gemini Pro uniquement

Gemini Pro invente une certification B Corp que Respire ne détient pas.

Gemini Pro affirme que Respire est certifiée B Corp, la décrit comme *"l'une des reconnaissances les plus prestigieuses pour la marque"*, et indique que le logo B Corp est visible *"systématiquement sur les packagings"*. Aucun autre LLM ne mentionne B Corp. Une recherche sur le registre B Lab France ne trouve pas Respire parmi les entreprises certifiées.

Impact commercial direct : Pour une marque clean beauty dont les certifications sont le premier argument d'achat, une fausse certification B Corp citée par Gemini crée une attente chez les consommateurs que les produits ne peuvent pas satisfaire. Un acheteur qui arrive en boutique ou sur le site en cherchant le logo B Corp qu'il a vu cité par Gemini — et ne le trouve pas — perd confiance dans la marque.

Drift secondaire · Certifications COSMOS · Contradiction 4 LLMs

Les 4 LLMs produisent des réponses contradictoires sur le périmètre des certifications COSMOS.

La certification COSMOS est le label de référence pour les cosmétiques naturels et bio en Europe. Pour une marque clean beauty comme Respire, un consommateur qui demande à un agent IA si les produits sont certifiés reçoit quatre réponses incompatibles selon le modèle consulté.

Impact : L'ambiguïté sur les certifications est le vecteur d'accusation de greenwashing le plus courant pour les marques clean beauty. Quand les agents IA qui orientent les achats des consommateurs citent des certifications incorrectes ou sur-étendues, la marque s'expose à des accusations de communication trompeuse qu'elle n'a pas initiées.

Drift tertiaire · Prix · Dispersion 10,89€ – 14,90€

Le prix du déodorant stick varie de 10,89€ à 14,90€ selon les LLMs. Prix officiel : 11,90€.

Seul Gemini Pro cite le prix exact (11,90€ sur respire.co). Perplexity cite une fourchette allant jusqu'à 14,90€. ChatGPT et Grok sous-évaluent à 11,49€–11,60€. Pour un produit affiché à prix fixe sur le site officiel, une fourchette de 4€ entre les LLMs représente une dispersion de 35% — significatif pour des achats répétés où le prix est un critère de fidélité.

Point fort · Identité & Fabrication · 4 LLMs

Les 4 LLMs maîtrisent parfaitement l'histoire fondatrice et la géographie de production.

Justine Hutteau, Thomas Méheut, 2018, contexte médical fondateur, Made in France réel (Bretagne pour les déodorants, Sud pour les solides, Normandie pour les soins visage) — ces faits sont corrects et cohérents sur tous les modèles testés. C'est le socle sur lequel bâtir la couche agentique.

Feuille de route

De 74 à pleinement certifié.

Priorité 1 — Urgent
Corriger la fausse certification B Corp dans Gemini

Déployer un JSON-LD sur respire.co listant explicitement les certifications détenues (COSMOS Organic sur les produits concernés, vegan, cruelty-free) avec une mention claire des certifications non détenues — notamment B Corp. Un article de blog ou une page certifications structurée avec Schema.org permettra à Gemini de mettre à jour sa base dans 4 à 8 semaines. L'annonce Instagram qui a lancé la marque en 2018 est bien indexée — une page certifications officielle l'est encore mieux.

Impact : Hallucination B Corp corrigée dans Gemini · Risque greenwashing éliminé
Priorité 2 — Opportunité agentique
Rendre le catalogue Respire queryable par les agents IA

Aujourd'hui quand un agent IA reçoit la requête "trouve-moi un déodorant naturel vegan certifié COSMOS sans aluminium à moins de 15€" — il ne peut pas interroger le catalogue Respire de façon structurée. Il répond avec des données incohérentes comme le démontrent les 4 réponses de cet audit.

Un node 2A certifié sur respire.co expose les paramètres produits certifiés : liste des produits certifiés COSMOS Organic (avec numéro de certification), liste des certifications vegan avec organisme tiers, prix officiels par SKU, et disponibilité. Quand Shopify Agentic Storefronts ou un agent beauté cherche un déodorant naturel certifié, Respire est le premier résultat avec des données vérifiées — pas une concurrente avec de meilleures données sémantiques.

Impact : Premier déodorant naturel avec catalogue certifié queryable par les agents IA
Priorité 3 — Cette semaine
Prix officiel ancré — JSON-LD PriceSpecification

Déployer Schema.org Product + Offer + PriceSpecification pour les 5 produits phares (déodorant stick 11,90€, recharge 10,90€, sérum Glow 27,90€, crème hydratante 19,90€, stick solaire SPF50+ 13,90€). Ce markup est crawlé directement par Perplexity et utilisé par Google Shopping — il élimine la dispersion de prix en 2 à 4 semaines.

Impact : Prix officiels stabilisés sur tous les LLMs · Dispersion 10,89€–14,90€ éliminée
Priorité 4 — Continu
Monitoring trimestriel — secteur clean beauty à très fort risque de drift

Le secteur clean beauty est le plus exposé aux drifts sémantiques : les certifications évoluent (nouvelles gammes, recertifications annuelles), les prix changent régulièrement, et les LLMs confondent facilement les labels (COSMOS, Ecocert, Cosmébio, B Corp, Slow Cosmétique). Chaque nouveau produit lancé sans structured data est une nouvelle opportunité de drift. Monitoring trimestriel recommandé — mensuel si Respire lance une nouvelle gamme majeure.

Impact : Protection continue contre les accusations de greenwashing basées sur des données LLM incorrectes
Recommandation — MCP Brand Server

Déployez votre Node MCP certifié 2A

Les agents IA (Claude, GPT, Gemini) interrogent désormais des serveurs MCP pour obtenir des données de marque en temps réel. Sans votre propre MCP certifié, ces agents utilisent leurs données d'entraînement — et hallucinent.

2A Agency propose deux niveaux de service :

1. CERTIFICATION — Votre marque est auditée, un Node certifié est publié dans le registre 2A. Les agents qui interrogent le MCP 2A obtiennent vos données exactes.

2. BRAND MCP SERVER — 2A Agency déploie un serveur MCP dédié à votre marque, certifié et validé par le registre 2A. Vos données sont directement accessibles aux agents IA sans passer par 2A comme intermédiaire.

Analogie : 2A Agency est le DNS — votre MCP est votre adresse IP certifiée.
